# Hook library for Ortal's LinkedIn posts

## Hook principles

Hooks should:

- Feel human
- Create recognition or curiosity
- Start with a moment, not a lecture
- Be short and readable
- Feel like something actually happened

## Hook types

### 1. Funny real-life hook

- I asked my agent for one simple thing. That was optimistic.
- Yesterday my AI wrote a post so polished, even I did not trust it.
- I wanted automation. Somehow I adopted a digital coworker with opinions.
- I asked for a caption. I got a TED Talk.
- Sometimes AI saves me an hour. Sometimes it creates a brand new hour.

### 2. Builder tension hook

- Building with AI is fun right until the output sounds nothing like you.
- The hardest part is not getting AI to write.
- It is getting AI to stop sounding like everyone else.
- A lot of people think a content agent is just prompt in, post out.
- It is not.

### 3. Character hook

- Working with AI sometimes feels like managing a brilliant intern who never sleeps.
- My agent can write. The problem is that sometimes it writes like a man in a blazer from 2019.
- There is a very specific moment when your agent starts sounding smart but not sounding like you.

### 4. Insight hook

- The problem with AI content is not that it is bad.
- It is that it is often too polished to feel alive.
- A good agent is not just productive.
- It is usable.
- Most people do not need more AI output.
- They need better AI behavior.

### 5. Comic / story hook

- Scene: me, five tabs open, one half-finished prompt, and an agent acting confident for no reason.
- Small update from the AI trenches:
- Real conversation I had with my agent this week:
- This is what building with AI actually looked like yesterday:

## Hook filter

Reject any hook that sounds like:

- A lecture
- A whitepaper intro
- A vague industry statement
- A generic "AI is changing everything" line

## Best practice

The first two lines should make the reader think one of these:

- I know this feeling
- Where is this going
- Okay, that is funny
- This person actually builds
