# LinkedIn draft scoring

Score every draft from 1 to 10.

## 1. Readability

Would a normal person actually read this without effort?

## 2. Hook strength

Do the first two lines create curiosity, recognition, or a smile?

## 3. Relatability

Does this feel like a real moment, not a content machine output?

## 4. Personality

Can we feel Ortal in this?

## 5. Memorability

Is there at least one line people may remember or quote back?

## 6. Positioning

Does this quietly position Ortal as a capable AI / growth builder?

## 7. Virality potential

Does this include tension, humor, contrast, honesty, or a useful observation?

## Automatic rejection rules

Rewrite if:

- Readability < 8
- Personality < 8
- Relatability < 7
- Hook < 7

## Extra rejection rules

Reject the draft if:

- It sounds like thought leadership theater
- It sounds like a generic AI influencer wrote it
- It sounds too bitter
- It has no scene, no tension, and no payoff
