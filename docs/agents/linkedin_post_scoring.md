# LinkedIn Post Scoring

Score each draft from 1–10 on:

1. **Human readability**
   Would a normal person read this without feeling it is too high-level?

2. **Hook strength**
   Do the first two lines create curiosity or recognition?

3. **Relatability**
   Does this feel like a real moment or real builder experience?

4. **Personality**
   Can we feel Ortal in this post?

5. **Virality potential**
   Does it contain tension, contrast, humor, or insight people may react to?

6. **Clarity**
   Can it be understood quickly on mobile?

7. **Soft positioning**
   Does it indirectly position Ortal as a strong AI builder / growth-minded creator?

## Hard rules

- If readability < 8: rewrite
- If relatability < 7: rewrite
- If personality < 8: rewrite
- If it sounds like a lecture: rewrite
- If it sounds too negative without payoff: rewrite
