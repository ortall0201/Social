# Caption library

## Purpose

Provide short, comic-style image captions for character-driven LinkedIn visuals.

These captions are for the **image** itself.

They should be short, punchy, readable, and emotionally clear.

**Rules and voice:** [`comic_caption_rules.md`](./comic_caption_rules.md).

## Tone

- tactical
- witty
- builder-minded
- dry humor
- not childish
- not meme-spam
- not random

## Caption types

### Me vs agent

- one simple edit
- agent mode: overconfident
- not bad. not me.
- wrote the post. missed the vibe.
- now we debug personality too
- yes, the bot has opinions
- this was supposed to be easy
- confidence not included
- impressive. unusable.
- great output. wrong human.

### Me vs chaos

- tactical chaos
- still under control
- five tabs later
- this escalated quickly
- workflow pending
- systems everywhere
- calm. ish.
- this is fine engineering
- organized enough
- one thing became seven

### Me vs tone

- too polished
- less keynote, more human
- rewrite activated
- not a TED Talk
- lower the altitude
- clearer. sharper. realer.
- sounds smart. not me.
- nice words. wrong voice.
- tone correction in progress

### Me vs automation fantasy

- saved time allegedly
- automation added homework
- efficiency took a detour
- delegated. then babysat.
- still faster than manual
- almost automated
- built for speed
- now with extra steps
- optimization with side effects

### Tactical builder energy

- tactical rewrite activated
- mission: usable output
- operator mode
- debug first
- sharp systems only
- useful beats impressive
- builder under pressure
- no fluff detected
- workflow secured
- signal restored

## Rules

- max 2 to 5 words preferred
- should be readable at a glance
- should support the scene, not explain the whole story
- should sound like part of a series
- should feel consistent with Ortal's voice

## Final rule

If the caption sounds generic, motivational, or too internet-random, reject it.
