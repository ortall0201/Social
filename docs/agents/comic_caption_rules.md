# Comic caption rules

## Purpose

The comic image and caption should work together.

The image gives the scene.

The post text gives the meaning, humor, or insight.

## Character

The visual character is: **G.I. Jane tactical supergirl** figure (see [`ortal-linkedin-gijane-supergirl-visual-persona.md`](./ortal-linkedin-gijane-supergirl-visual-persona.md)).

She should represent:

- Resilience
- Speed
- Tactical thinking
- Builder energy
- Controlled chaos
- Confidence under pressure
- Smart action, not passive branding

## Caption style

Comic captions should be:

- Short
- Punchy
- Readable
- Emotionally clear
- Not overloaded with text
- Visually aligned with the joke or tension

## Good caption examples

- me asking for one small edit
- agent mode: too confident
- wrote the post. missed the vibe.
- not bad. not me.
- tactical rewrite activated
- this was supposed to save time
- now we debug personality too
- yes, the bot has opinions
- prompt fixed. dignity pending
- built for speed, stayed for chaos

## Avoid in image captions

- Long explanations
- Corporate phrases
- Jargon-heavy text
- Paragraphs
- Generic motivational words

## Rule

Image captions should create **instant recognition**.

The post body can go deeper.
