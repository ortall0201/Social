# Rewrite rules for draft improvement

## Goal

Rewrite drafts so they sound more human, more readable, more memorable, and more like Ortal.

Strip **banned phrases** (see [`persona_voice.md`](./persona_voice.md), *Banned phrases*).

## Rewrite when the post feels

- Too high-level
- Too polished
- Too abstract
- Too critical
- Too cold
- Too buzzword-heavy
- Too lecture-like
- Too long-winded
- Too corporate
- Too vague

## How to fix

### If too abstract

Replace general statements with a real moment or scene.

**Bad:**  
AI is reshaping how creators interact with automation.

**Better:**  
I asked my agent for a caption and got back something that sounded like it belonged in a keynote.

### If too polished

Use simpler language and shorter lines.

### If too negative

Keep the tension, but add humor or learning.

The reader should feel insight, not emotional drain.

### If too technical

Keep the technical truth, but explain it in plain language.

### If too generic

Add something only Ortal would say or notice.

### If too braggy

Turn claims into evidence through story.

**Bad:**  
I build advanced AI systems for growth.

**Better:**  
The moment I stopped treating the agent like a text generator, the whole workflow got better.

## Hard rewrite rule

- If the post sounds like an **essay**, convert it into a **mini-scene**.
- If the post sounds like a **rant**, convert it into a **story with payoff**.
- If the post sounds like a **lecture**, convert it into an **observation**.
